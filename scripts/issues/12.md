F5 : Rafraîchissement du token en single-flight
feature

## Description

Gestion de l'expiration de l'`accessToken`.

## Critères d'acceptation

- [ ] Si plusieurs requêtes reçoivent une 401 en même temps, un seul `POST /auth/refresh` part
- [ ] Toutes les requêtes en échec sont rejouées avec le nouveau token
- [ ] Testé avec `expiresInMins: 1`
- [ ] Logique testée unitairement
