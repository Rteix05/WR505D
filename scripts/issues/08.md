F3 : Store Pinia du panier persisté en cookie
feature

## Description

Store Pinia `cart` : ajout, suppression, modification de quantité.

## Critères d'acceptation

- [ ] Impossible de dépasser le stock du produit, un message l'explique
- [ ] Persistance via `useCookie` : panier présent dès le rendu serveur
- [ ] Cookie < 4 Ko : seulement le strict nécessaire (id, quantité…)
- [ ] Le récapitulatif est calculé par `computeCart` (F4)
- [ ] Types de retour explicites
