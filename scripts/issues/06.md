## Description

Page détail d'un produit.

## Critères d'acceptation

- [ ] Galerie d'images, description, marque, note, stock, garantie, livraison
- [ ] « Plus que X en stock » si stock < 5 ; bouton désactivé et « Rupture de stock » si stock = 0
- [ ] `useSeoMeta` : titre, description, Open Graph avec image
- [ ] Identifiant inexistant : vraie 404 via `createError`
