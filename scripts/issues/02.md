F1 : Catalogue paginé /produits
feature

## Description

Page `/produits` listant les produits, 12 par page.

## Critères d'acceptation

- [ ] 12 produits par page avec image, titre, prix, note et badge « −X % » (`discountPercentage`)
- [ ] Pagination accessible au clavier
- [ ] La page courante est dans l'URL (`?page=`)
- [ ] États gérés : squelettes au chargement, « aucun résultat », erreur réseau avec bouton « Réessayer »
- [ ] Rendu côté serveur (fonctionne JavaScript désactivé)
