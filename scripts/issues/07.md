## Description

Fonction pure `computeCart(lines, promoCode?)` avec la signature imposée par le sujet. Montants en centimes.

## Critères d'acceptation

- [ ] Remise beauté : au moins 3 articles beauty → −10 % par ligne beauty, arrondi demi vers le haut ligne par ligne
- [ ] Code TROYES10 : −10,00 € si sous-total après remise beauté > 50,00 €, insensible à la casse et aux espaces ; `messages` explique un refus
- [ ] Plafond : remises ≤ 25 % du brut, le code promo est réduit en cas de dépassement
- [ ] Livraison 4,90 €, offerte dès 80,00 € après remises, sauf si produit `furniture`
- [ ] `tests/unit/promotions.spec.ts` couvre les 8 scénarios du sujet + cas limites (panier vide, code inconnu, quantité 0…)
- [ ] Couverture ≥ 90 % lignes et branches (seuil déjà configuré dans `vitest.config.ts`)
