Types DummyJSON et client API
feature

## Description

Typer les réponses DummyJSON dans `types/dummyjson.ts` à partir des réponses réelles, et centraliser les appels API.

## Critères d'acceptation

- [ ] `types/dummyjson.ts` exporte `Product`, `ProductsResponse`, `Review`, `Category`, `User`, `AuthTokens`
- [ ] Types écrits à partir de réponses réelles (pas de `any`, `unknown` + narrowing si besoin)
- [ ] L'URL de base vient de `runtimeConfig.public.apiBase`
